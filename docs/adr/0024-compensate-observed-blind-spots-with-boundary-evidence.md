# ADR 0024: Compensate observed blind spots with boundary evidence

- Status: Accepted
- Date: 2026-08-17

## Decision

When repeated held-out runs miss the same consequential property, first reduce competing instruction load and route detail progressively. If the miss persists, add the smallest observable compensation at the property boundary rather than another general reminder, checklist, reasoning ritual, or report form. Place a non-obvious recurrent correction where the executor will see it before the affected decision, state the outcome that must be observed, and preserve an honest fallback when the preferred isolation mechanism is unavailable.

For mutation-capable AI-audited mechanisms, distinct logical roles are not evidence of distinct runtime objects. When the target protects some state while authorizing other state to change, the audit retains before/after evidence showing whether allowed caller bindings preserve that authority boundary. A fresh context is preferred because prior findings can select its search, but the primary agent still performs the targeted observation when fresh isolation is unavailable and reports the loss of independence. An earlier blocker does not remove this repair-changing boundary.

This is a demonstrated model compensation, not a universal audit sequence. It applies only when the target exposes the named mutation/authority property and remains removable when fresh dissimilar evaluation shows that the behavior is reliably covered without it.

## Why

Skill Auditor 3.2 improved authority calibration and no-clobber discovery, but every compared audit missed an eDNA builder invocation where `--replace` let the output role resolve to a protected input and destroy it. Two plausible prose interventions failed: a composition reminder recovered the defect once in three runs while increasing cost, and a generic independent-challenge instruction recovered it zero times in three while losing another established finding once.

The 3.3 experiment first reduced the always-loaded skill body from 1,995 to roughly 1,100 words and routed executable detail to a focused reference. Two fresh low-reasoning runs still missed the protected-input defect. An optional isolated-observer direction recovered it in one run and was skipped in another. A fresh-observer-only requirement made one run report the gap honestly but did not discover the defect when no observer was used. The accepted form made the target-owned before/after observation unavoidable while allowing the primary context as a disclosed fallback.

All three fresh accepted-form runs then recovered the destructive input overwrite and preserved the known UTC, numeric-order, and containment defects. Three blind reviewers independently preferred the accepted-form audits over same-model reports that lacked the compensation because the added defect materially expanded repair scope. On a dissimilar satellite-bundle target, a clean source-provenance run found both the target's deadline/verifier failure and a successful same-path write that destroyed the authorized input plan. A second clean replicate preserved the deadline/verifier and instruction- design findings but did not classify the plan as explicitly protected, which correctly limits the compensation to authority distinctions the target actually adopts. A separate orbit run was excluded after its retired 3.1 report vocabulary showed that an installed same-name skill had contaminated the condition; prompt-assigned paths alone were therefore also rejected as exposure proof.

Current [Agent Skills evaluation guidance](https://agentskills.io/skill-creation/evaluating-skills), [Agent Skills best practices](https://agentskills.io/skill-creation/best-practices), and [Anthropic skill guidance](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices) independently support the surrounding design: keep always-loaded instructions concise, use progressive disclosure, evaluate in fresh contexts, compare against a baseline, retain executable evidence for objective assertions, and use fresh review for unanticipated issues. Those sources support the method but do not substitute for the held-out outcomes above.

## Consequences

Skill Auditor 3.3 loads a smaller semantic kernel, routes executable mechanisms to a focused reference, and carries one prominent mutation-boundary compensation with its evidence and removal condition. It does not add a keyword scanner, policy-scoring script, fixed edge catalog, named reasoning method, report template, or universal agent count.

Behavioral trials must retain the source actually loaded. An installed or cached same-name skill can contaminate a candidate even when a prompt names another path; ambiguous or mixed-source runs are excluded rather than attributed.

This evidence raises confidence and corrected the observed 2-of-3 preference result to 3-of-3 on the tested comparison. It does not justify a promise that stochastic agents will win every future audit or discover every defect. Reopen the decision if the compensation causes material false positives or cost on dissimilar targets, if supported models reliably cover the property without it, if host isolation changes, or if broader assurance is again claimed.
