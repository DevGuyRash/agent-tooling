# Visualization

Visualization helps an agent make anything visible to the people who need to grasp it, in whatever form serves them. Visual Authoring is the general entry: it starts from what the reader must understand, feel or do, explores genuinely different directions before committing, uses whatever the environment offers, presents the information faithfully with its uncertainty and gaps, and revises from the actual result. Mermaid is a format guide for when Mermaid is requested or chosen, with a bundled reference to its documented diagram types. Both entries are independently callable, and neither makes any form the default.

The plugin is instruction-led. It ships no renderer, framework or report library, installs no dependencies and requires no particular model; authors use the tools the receiving environment provides and keep the delivery requirements they are given. Split Testing's report library remains owned by Agentic Design & Evaluation and is not required here.

The repository's authoring guidance governs development of these instructions. The installed plugin is self-contained at runtime, and both supported host variants preserve its resources and automatic discovery.
