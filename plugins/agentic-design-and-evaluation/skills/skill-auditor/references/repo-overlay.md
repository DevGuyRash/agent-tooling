# Repository Overlay

Repository instructions govern work and targets within their stated scope. Discover the applicable repository authority from the actual checkout; an installed audit tool does not bring its author's entire repository policy with it. External targets adopt such rules only through their own authority or the user's mandate.

The reporter source tag `repo-overlay` identifies a possible repository convention, such as display-name consistency, shell launchability, or cold-start artifacts. Establish its actual adoption before treating it as a requirement of the target. `open-standard` concerns the portable contract; `plugin-fit` concerns composition and delivery. A source tag does not grant release authority.
