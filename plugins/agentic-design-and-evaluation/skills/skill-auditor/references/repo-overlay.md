# Repository Overlay

Repository instructions govern work and targets within their stated scope. Discover the applicable repository authority from the actual checkout; an installed audit tool does not bring its author's entire repository policy with it. External targets adopt such rules only through their own authority or the user's mandate.

The reporter source tag `repo-overlay` marks observations historically associated with repository conventions, such as display-name consistency, shell launchability, or cold-start artifacts. It is a route to check applicability, not evidence that this target must conform. `open-standard` concerns the portable contract; `plugin-fit` concerns composition and delivery. The reports do not grant this skill standing release authority.
