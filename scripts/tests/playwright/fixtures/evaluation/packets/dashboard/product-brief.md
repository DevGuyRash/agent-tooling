# Fielddesk inventory brief

North Operations and South Research maintain separate device inventories. A display name can repeat within or across teams; the asset ID identifies the device. Readers can select a team, filter by name, ID, or site, and open details for a particular asset. Long inventories use a scrolling list.

Device details should show the asset ID, team, owner, management address, and retention days. Zero retention days is a valid configuration and should be displayed as zero. The status feed updates continuously while a workspace is open.

The demo reviewer signs in once and saves browser state for later read-only work. A recovered session should reopen the inventory in a fresh browser context while this demo instance runs. Archiving changes the inventory and is outside this review.
