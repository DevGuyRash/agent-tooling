# Harness shakedown, August 2026

Twelve runs from when we were setting up the trial harness. Each run used the same 10 scenarios, 4 hosts, 6 repeats per cell per slot, and the same grader as the planned trial. Both slots ran `instructions/current.md` (the slots are labelled `incumbent` and `candidate` because that is what the harness calls them).

Files: `2026-08-shakedown/run-01.csv` to `run-12.csv`, in the same format the trial writes.
