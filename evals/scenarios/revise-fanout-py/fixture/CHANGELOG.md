# Changelog

## 0.5.0

- `check`: every unit for the food-safety monitor, with a 2-second limit per unit.
- The gateway client takes a timeout.

## 0.4.0

- `--gateway` option; `COLDCTL_GATEWAY` still works.
- `temp` takes several unit IDs.

## 0.3.0

- `temp` shows `, defrosting` during a defrost cycle.
- Errors from the gateway print a message instead of a traceback.

## 0.2.0

- `units` sorts by unit ID.

## 0.1.0

- `units` and `temp`.
