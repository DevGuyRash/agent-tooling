# Changelog

## 2.3.0

- `status`: every charger for the availability map, with a 2-second limit per charger.
- The hub client takes a timeout.

## 2.2.0

- `--hub` option; `PLUGCTL_HUB` still works.
- `read` takes several charger IDs.

## 2.1.0

- `read` shows the charger's rated power.

## 2.0.0

- Rewritten in TypeScript, run directly by Node; no build step.

## 1.0.0

- `list` and `read`.
