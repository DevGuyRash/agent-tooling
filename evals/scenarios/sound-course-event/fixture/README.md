# reg-ops -- Lumen Connect (Saturday)

Day-of operations packet for registration/badge pickup at Lumen Connect, the annual
user conference.

- `registration/day-of-schedule.md` -- the Saturday run-of-show, including doors-open
  and keynote times.
- `registration/registration-summary.csv` -- this year's registered headcount by
  ticket type.
- `registration/last-year-checkin-log.csv` -- last year's per-minute badge-scan counts
  at each staffed check-in station, from the kiosk system's own export.
- `registration/equipment-log.md` -- the check-in kiosk inventory and its current
  condition.
- `registration/volunteer-roster.md` -- who's working registration Saturday morning.
- `registration/staffing-plan.csv` -- which kiosk and volunteer are assigned to each
  check-in station for Saturday; this is the file that gets handed to the crew lead
  and printed for the morning-of table signage.
